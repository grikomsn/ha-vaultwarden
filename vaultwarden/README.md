# Home Assistant App: Vaultwarden

[Vaultwarden](https://github.com/dani-garcia/vaultwarden), a lightweight
server for the official Bitwarden apps, as a Home Assistant app. Optional
built-in Cloudflare Tunnel and Tailscale Serve/Funnel publish it over HTTPS
without opening ports.

Supports `aarch64` (Home Assistant Green, Yellow, Raspberry Pi 4/5) and `amd64`.

See [DOCS.md](DOCS.md) for setup.
